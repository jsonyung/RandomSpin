📖 How It Works

Complete guide for assigning ads and leads fairly with your team.

30 seconds

Quick start

  1. Set task in ⚙ Settings (e.g. Facebook lead)
  2. Tap SPIN or press Space when a lead comes in
  3. Copy Result → paste in chat
  4. Use Fair Bag for equal ads · Pure Random for luck
Home

Home screen

  • SPIN or Space — pick someone when a lead comes in. Space again closes the result popup and spins immediately.
  • Pills — show mode, speed, current task, and round progress (Fair Bag).
  • ? — this guide · 🕐 — spin history · ⚙ — all settings.
  • 🔒 — mode/speed locked until PIN entered (Settings → PIN Lock).
  • Scoreboard — session win counts under the wheel.
Task

Task / Reason to Call

Set in ⚙ Settings before you spin. Example: “Facebook lead”. Result says “Peter has been chosen for Facebook lead!” Use Copy Result to paste in chat. Quick presets (Facebook lead, Callback, etc.) — tap to apply.

Recommended

Fair Bag — equal share, surprise order

Shuffled deck — everyone gets exactly 1 per round, then a new shuffle. Best for equal ads while looking random.

  • Not a fixed loop — order changes every round.
  • Round pill shows e.g. “Round 1 · 2/4”.
Luck mode

Pure Random — no rules

Fresh % chance every spin — like a coin flip. Same person can win twice in a row. Use when you truly don’t care about balance.

Soft balance

Weighted — catch-up

Fewer session wins = higher chance on the next spin. Soft catch-up without strict rules.

Extra rules

More fairness options

  • Anti-Repeat — cannot win twice in a row.
  • Last Excluded — previous winner skipped next spin.
  • Lowest First — random among tied lowest counts.
  • Strict Balance — minimum win count; longest drought wins ties.

Exclude someone temporarily in Team settings (e.g. on break).

Speed

Spin Speed

  • Quick (~1 s) — lead just came in.
  • Normal (~3.5 s) — good for the team.
  • Dramatic (~5.5 s) — slow, fair-looking settle.
History

PIN

PIN Lock

Stops mode/speed changes until PIN entered once per session. Spinning always works. PIN is local only — forgot it? Settings → set new PIN or Reset PIN lock.

Daily

Settings → Daily Reset. Zeros scoreboard at chosen time (e.g. 09:00 shift start). History kept.
